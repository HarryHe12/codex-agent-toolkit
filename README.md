## 组件分工

| 基础组件 | 负责 |
|---|---|
| local-code-guard | 本地可执行门禁与基线 |
| instruction-maintenance | 唯一归属、草稿及独立语义审查 |

| 工程方法 | 负责 |
|---|---|
| project-verification | 实跑产品、证据与按需地图 |
| prevent-repeat-errors | 将重复错误变成结构或检查 |
| evaluate-agent-skills | 同条件对照、成本与结论边界 |
