# P2 配对回放

在两个隔离工作区分别安装发布包的 P1 和 P2。每对使用相同的 Git 初始文件、首稿改动、项目验证命令和独立验收。两组都运行真实检查器，反转相邻场景的运行顺序。P2 额外显式执行已审阅的行为验收计划。

五个新场景覆盖文档示例漂移、太弱的库存重试测试、错误的金额输出、正确的权限调整和无关文案改动。业务预期按场景里的独立规则预先写定。下游验收直接调用应用，核对文档示例，并用另写的错误输出检查关键测试。

记录首次收尾结果，下游验收发现的问题，以及修正后能否通过。首次收尾通过且下游验收失败时，记为一次下游返工。分别统计首次通过数、下游返工和总修正次数。耗时取首次 `verify` 加模拟同会话 `Stop` 的墙上时间，不含安装、初始登记和下游验收。

本回放使用固定合成提案和修正，不调用模型。模型 token、费用、人工介入和真实业务交付耗时不在测量范围内。结果只适用于这批回放场景。

在项目根目录运行 `python3 evaluations/p2-20261123/run_replay.py --out /tmp/toolkit-p2-results.json`。安装使用缓存中的锁定依赖。
