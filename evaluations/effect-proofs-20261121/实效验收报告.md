# 优化机制是否兑现：实效验收

结论：本地代码硬检查确实生效，已经有真实 Agent 收到违规反馈后修正的案例。MD 治理只能证明部分效果；“自动防止语义重复、始终不产生垃圾规则”尚未兑现，不能作为保证。

本次按用户最新要求验证具体效果，不再用“整体是否更好用”作为验收目标。没有修改阈值、增加豁免或重置基线。

## 必须收回的过度承诺

- “防住所有语义重复”：没有证据；同段落完全重复句子也已有漏检。结构检查和逐条审阅记录不能证明规则含义正确。
- “MD 永远不会变脏”：没有文件系统写入拦截。直接编辑仍可能先写入错误内容，Hook 在工具结束后反馈并阻止正常收尾；采用正式草稿写入器时，已覆盖的结构错误才会在发布前被拒绝。
- “能自动识别过老实现”：目前只覆盖已有明确替代依据的废弃接口契约，不覆盖任意旧设计。
- “通过 lint 就证明业务正确、整个流程变好”：不成立；本次业务正确性由独立验收另查，也没有据此证明普遍提速或成功率提高。
